The academic documents and the artist CVs are drawn from the same record: the academic ones list it in full, the artist ones lead with practice and promote the pre-2019 design credits the academic CV keeps in an archive. The short artist CV is the same document cut for applications with a page limit.

Everything regenerates automatically from a single data source ([`cv.yaml`](cv.yaml)) on every update; the links above always serve the latest build.

## How this repo works

Everything is generated from `cv.yaml` by `build.py`, converted to PDF and Word by GitHub Actions, and committed to [`output/`](output/). Maintainer documentation is in [`CLAUDE.md`](CLAUDE.md).
